# Welcome to OtterKeep! 🦦

We build lightweight, modern, and open-source backup tools designed specifically for macOS.

By leveraging native APFS features like Copy-on-Write (`clonefile`) and the safety of modern Swift, OtterKeep helps you keep your files safe, space-efficient, and easy to restore—without unnecessary bloat.

### What you'll find here
* **Core Engine:** The high-performance, APFS-native backup CLI.
* **Distribution & Tooling:** Homebrew tap configurations, installation scripts, and utilities.
* **Ecosystem Components:** Supporting libraries and upcoming integrations for the macOS ecosystem.

Feel free to explore our repositories, open an issue, or contribute. Happy backups!
